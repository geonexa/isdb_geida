# 2026-11-09: Documentation and branding

**Release:** 2026-11-09 · **Action needed:** no

## Summary

GEIDA has a full documentation site and its own logo, shown beside the IsDB logo.

## What users will notice

- The navbar shows the **IsDB logo** and the new **GEIDA logo**.
- The **Terra and Expo City Dubai** logos are in the footer, bottom left, under
  "Powered by".

## What administrators must do

Nothing for the platform itself; `deploy.sh` as usual.

To publish the documentation, build it and copy the static site (see
[Maintaining the documentation](../development/documentation.md#publish)):

```bash
conda activate geida
pip install -r docs/requirements.txt
mkdocs build                         # -> site/
```

## Compatibility

- Database migrations: no
- API or URL changes: no
